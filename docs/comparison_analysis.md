## 六、关键差距总结

### 🔴 严重缺失（影响核心功能）
1. **m3u8 支持** — 参考应用支持 m3u8 播放列表解析和 ts 分片合并下载，当前项目完全不支持
2. **断点续传** — 参考应用实现完整，当前项目不支持，大文件下载中断需重下
3. **真实视频名提取** — 当前全部用 Video_1/2/3 占位，参考应用从 URL query string 中提取
4. **下载完成后打开文件夹** — 参考应用支持，当前项目缺失

### 🟡 中等差距（影响用户体验）
5. **全局取消下载** — 参考应用有 _globalCts，当前需逐个取消
6. **状态栏设计** — 参考应用有底部进度条+目录+统计，当前项目较简陋
7. **速度汇总显示** — 参考应用显示所有任务总速度，当前仅单个任务
8. **按钮状态管理** — 解析/下载中按钮应禁用，当前未实现

### 🟢 轻微差距（锦上添花）
9. **DPI 感知/自适应缩放** — 参考应用更精细
10. **视频列宽拖拽调整** — 参考应用支持
11. **路径省略号显示** — 参考应用有优化
12. **窗口关闭时取消下载** — 参考应用在 Closing 事件中处理

## 七、建议优先级

### 高优先级（必须实现）
- [ ] 改进 URL 正则：支持 m3u8、带参数的 URL
- [ ] 视频名提取：从 URL query 参数或 HTTP Header 中获取真实文件名
- [ ] 断点续传：支持已存在文件的 resume 下载
- [ ] 下载完成后打开文件夹功能

### 中优先级（强烈建议）
- [ ] 全局取消下载（_globalCts 模式）
- [ ] 改进状态栏：总体进度 + 实时总速度
- [ ] 按钮状态管理：解析中/下载中禁用相应按钮
- [ ] 视频列表排序（按名称/大小/状态）

- [ ] DPI 自适应缩放
- [ ] 窗口大小/位置持久化
