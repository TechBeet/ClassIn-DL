# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

We take security issues seriously. If you discover a security vulnerability, please follow these steps:

1. **Do NOT** open a public issue
2. Send an email to your-email@example.com with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

3. We will respond within 72 hours
4. Once fixed, we will credit you in the release notes (optional)

## Responsible Disclosure

Please allow time for the fix to be developed before disclosing the vulnerability publicly.
